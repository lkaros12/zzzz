# 머리카락 리깅·웨이트 작업 결과

파일: zombi1_hair_rigged.blend / zombi1_hair_rigged.fbx
기준: 이 작업 시작 시 저장되어 있던 zombi1_humanoid.blend
원본과 기준 파일은 덮어쓰지 않았습니다.

## 적용 대상
원점의 Armature / remesh에 적용했습니다. 옆에 놓인 Armature.001 / remesh.001 복제 모델은 그대로 두었습니다. 기존 Subdivision 설정도 유지했습니다.

## 추가한 본과 웨이트
- 뒷머리 5구간: HairBack_R2, R1, C, L1, L2
- 옆머리 2구간: HairSide_L, R
- 앞머리 3구간: HairBang_L, C, R
- 정수리 솟은 가닥 1구간: HairAhoge
- 각 구간은 _1 → _2 → _3의 본 3개로 연결됩니다. 총 33개입니다.
- 각 첫 본의 부모는 Head입니다. Head와 함께 움직이며 가닥 본을 따로 회전할 수 있습니다.
- 머리카락 제어 컬렉션: Hair - deform controls
- 머리카락 웨이트가 적용된 원본 정점: 43,967개. 그 밖의 37,148개 정점 웨이트는 기준 파일과 정확히 동일합니다.
- 뿌리에서 끝으로 영향을 부드럽게 바꾸고, 가닥 경계와 동일 좌표의 분리 정점 웨이트를 정리했습니다. 머리카락 영역은 최대 8개 본 영향을 사용합니다.

## 사용
수정본은 Armature의 Pose Mode에서 HairBack_C_1을 선택한 상태로 열립니다. Hair 컬렉션에서 원하는 본을 선택하고 회전합니다. _1은 뿌리, _2는 중간, _3은 끝을 제어합니다. 자동 흔들림 물리나 자동 애니메이션은 추가하지 않았습니다.

## 검증과 보존
- 기존 본 54개의 위치·방향·부모 연결 불변.
- 메시 좌표·면 연결·UV·재질·Subdivision 설정 불변.
- 복제 모델의 형상과 웨이트 불변.
- 각 머리카락 본 33개를 개별 회전하여 실제 변형과 머리카락 웨이트가 없는 정점의 이동 여부를 검사했습니다.
- 앞머리, 옆머리, 뒷머리, 솟은 가닥을 움직여 렌더링하고 웨이트를 반복 보정했습니다.
- 머리카락 웨이트가 없는 정점의 최대 수치 오차는 약 0.0000001 Blender 단위입니다.
- Unity에서 Avatar.isValid=True, Avatar.isHuman=True, 머리카락 본 33개 확인.

## 검증한 포즈와 제한
- 뒷머리: 각 체인의 뿌리 12도, 중간·끝 각 6도의 좌우 방향 회전.
- 옆머리: 뿌리 4도, 중간·끝 각 2도의 바깥 방향 회전.
- 앞머리: 뿌리 3도, 중간·끝 각 1.5도의 들어 올리는 회전.
- 솟은 가닥: 각 본 10도 회전.
- 이 수치는 테스트 포즈이며 강제 회전 제한은 아닙니다. 특히 얼굴·어깨와 가까운 앞머리·옆머리는 큰 각도에서 늘어남이나 관통이 남습니다. 원본 메시 형상을 보존했으며 자유롭게 크게 휘날리는 물리 헤어 수준으로 검증된 것은 아닙니다.
- 보정 후에도 일부 가닥 경계의 국소적인 늘어남은 남습니다. 모든 범위에서 무변형·무충돌이라는 의미는 아닙니다. 자세별 수치는 hair_pose_tests.json에 기록했습니다.

## Unity
Assets/RigValidationZombi1/zombi1_hair_rigged.fbx에 별도 가져왔으며 Humanoid 본 매핑을 유지했습니다. Import Settings의 Skin Weights는 Custom / Max Bones Per Vertex 8입니다.
현재 프로젝트의 실행 시 Skin Weights 설정은 FourBones이므로 Blender의 8개 영향과 완전히 동일하게 평가되지 않을 수 있습니다. 프로젝트 전체 품질 설정은 변경하지 않았습니다. 동일한 웨이트 품질이 필요하면 실행 환경의 Skin Weights를 Unlimited로 설정해야 합니다.
