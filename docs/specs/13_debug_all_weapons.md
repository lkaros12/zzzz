# 작업: 테스트용 — 모든 무기를 시작 인벤토리 + 옆 상자에

원칙(AGENTS.md): 모호하면 멈추고 보고 / 최소 코드 / 관련 줄만 / 목표 확인. UTF-8·한글 주석, perl 금지, Unity 조작·커밋 금지.

## 사용자 요구
"인벤토리에 실험하게 무기들 다 넣어줘". 무기 17개 합계 94칸, 인벤토리 8×6=48칸이라 다 안 들어간다 (메인 결정: 넘치는 건 옆 상자).

## 만들 것 (`Assets/_Game/Scripts/Player/DebugStartState.cs` 중심)
1. `[SerializeField] bool giveAllWeapons = true;` — 켜면 카탈로그의 **모든 무기·방패**(handedness != None 또는 isShield 인 아이템)와 **모든 탄약**(ammo_* , 각 60발)을 준다. 기존 startingItems 는 그대로 먼저 준다 (식칼·방패·권총 장착 흐름 유지).
2. 인벤토리에 순서대로 넣고, **안 들어가는 것은 플레이어 시작 위치 옆(1.5m, 벽·가구와 안 겹치는 곳)에 테스트 상자**를 하나 만들어 담는다.
   - 씬의 기존 상자(컨테이너) 컴포넌트를 재사용 (새 컨테이너 클래스 금지). 상자 이름 "테스트 무기 상자". 필요하면 상자 크기를 넉넉히(모두 들어가게).
   - 상자는 런타임 생성이어도 되고 빌더가 씬에 두어도 된다 — 짧은 쪽. 세이브/불러오기에서 문제(중복 생성) 없게.
3. 로그 한 줄: 인벤토리에 넣은 개수, 상자에 넣은 개수.
4. 자기검사(별장 Self Check): 무기 17종 + 탄약 4종이 인벤토리+상자 합쳐 모두 있다 (에디트 모드로 가능한 범위 — 불가능하면 이유 적고 메인이 재생 모드에서 확인).

## 하지 말 것
인벤토리 크기 변경, 무기 데이터 변경, 실제 게임 시작 아이템 규칙 변경(테스트 전용 플래그로만).

## 출력
변경 파일 목록과 요약만. 상자 생성 방식, 막힌 것.
