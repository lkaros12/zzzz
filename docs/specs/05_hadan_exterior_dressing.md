# 작업: 하단 도시 건물 외부·거리 꾸미기

## 원칙 (AGENTS.md 와 같다)
1. Think Before Coding — 명세가 모호하거나 코드와 안 맞으면 추측하지 말고 멈추고 보고한다.
2. Simplicity First — 최소 코드. 기본 도형(큐브·실린더)과 코드 생성 텍스처만. 새 셰이더·외부 에셋·블렌더 금지.
3. Surgical Changes — `HadanCityBuilder.cs` 안에서만. 별장 빌더·런타임 스크립트 변경 금지.
4. Goal-Driven Execution — 완료 기준별로 무엇이 확인하는지 남긴다.
- UTF-8, 한글 주석("왜"), **perl 편집 금지**. Unity 에디터 조작·커밋 금지.
- 04(씬 이동)가 먼저 들어간다. 04 가 넣은 `Arrive_FromEstate`(= 시작점) 주변은 비워 둔다.

## 배치 규칙 공통
- **결정적 난수**: 건물 id / 도로 id 로 시드. 재빌드해도 같은 모양.
- 소품끼리, 그리고 건물 외곽·플레이어 시작점과 겹치지 않는다.
- 같은 종류는 **메쉬·재질 공유**, 정적 배칭(`BatchingStatic`), 재질은 GPU Instancing 켬.
- 새 메쉬·텍스처·재질은 기존 `Assets/_Game/Data/Hadan/` 과 `Materials/hadan_*` 규칙을 따른다. 재빌드해도 누적되지 않는다.

## 만들 것
1. **창문·층 구분선**: 건물 옆면 UV 를 월드 미터 기준으로 (u = 둘레 거리 / 3.0m, v = 높이 / 3.6m).
   코드로 만든 타일 텍스처 1장(한 칸 = 폭 3m × 한 층: 벽, 가운데 창문, 아래쪽 층 구분선). 건물 재질 3개가 이 텍스처를 공유하고 색만 다르다.
   지붕 면은 창문 없이 단색 (지붕 UV 를 창문 타일 영역 밖 단색 부분으로 보내거나 서브메쉬 — 짧은 쪽).
2. **1층 출입문·상가 차양**: 건물마다 **도로에 가장 가까운 외곽 변** 하나에 문(어두운 얇은 판, 폭 1.2m, 높이 2.2m, 벽에서 2cm 밖).
   그 변이 primary/secondary/tertiary 도로에서 15m(월드) 안이면 **상가**로 보고, 변 길이의 60% 폭 차양(높이 2.8m, 깊이 1.2m, 약간 기울임, 색 4가지 중 하나)을 단다.
   문·차양은 콜라이더 없음 (통행 방해 금지).
3. **옥상 소품**: 건물마다 난간(지붕 외곽을 따라 높이 0.8m 얇은 벽, 콜라이더 없음). 면적 100㎡ 이상이면 물탱크(실린더) 0~1개,
   실외기(작은 박스) 0~3개를 지붕 안쪽에 (외곽에서 1m 이상 안쪽, 지붕 삼각형 안).
4. **거리 소품** (도로 폭 가장자리 기준):
   - 가로수: primary·secondary 양쪽, 15m 간격. 줄기 실린더 + 잎 덩어리. 줄기에만 CapsuleCollider.
   - 전봇대: tertiary·residential·service 한쪽, 30m 간격. 실린더 + 가로대. 콜라이더 있음.
   - 버려진 차: primary·secondary·tertiary 도로 위, 도로 1km(월드)당 약 8대, 도로 방향으로 약간 틀어서. 박스 몸체 + 지붕 박스, BoxCollider 있음.
     NavMesh 굽기에 반영 (정적).
   - 모든 거리 소품은 건물 외곽에서 1m 이상 떨어진다.
6. **도시 부활 위치 (04 검수, 기존 문제)**: 도시 플레이어의 `PlayerDeath` 에 스폰 지점이 연결되지 않아 원점 반경 6m 에서 부활해 건물에 낄 수 있다.
   `Arrive_FromEstate` (시작점) 를 부활 지점으로 연결한다. 자기검사 7: 도시 PlayerDeath 의 부활 지점이 시작점이다.
5. 로그 한 줄 요약에 소품 수(문, 차양, 옥상, 나무, 전봇대, 차)와 전체 삼각형 수를 더한다.

## 성능 한도 (메인이 잰다)
- 씬 고유 메쉬 삼각형 150,000 이하 (로그), 재생 프레임 12.4ms → **+3ms 이하**, NavMesh 굽기 20초 이하.

## 자기검사 (`Tools/V0.1/Check Hadan Pilot` 에 추가, 기존 검사 유지)
1. 모든 건물에 문 1개. 상가 차양 수 > 0.
2. 차양·문·난간에 콜라이더 없음. 차·전봇대·나무 줄기에 콜라이더 있음.
3. 거리 소품이 어떤 건물 외곽 1m 안에도 없다. 시작점 반경 5m 안에 차·전봇대·나무 없음.
4. 옥상 소품이 모두 자기 건물 지붕 높이 위, 외곽 안쪽에 있다.
5. 시작점에서 15~50m 경로 검사가 여전히 통과한다 (차가 길을 막지 않았다).
6. 재빌드 2번 후 `Assets/_Game/Data/Hadan/` 파일 수가 같다.

## 하지 말 것
실내, 들어갈 수 있는 문, 간판 글자, 밤 조명·창문 불빛, 도로 차선, 인도 높이 차, 신호등, 좀비·아이템.
