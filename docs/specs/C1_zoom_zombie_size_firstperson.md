# 작업: 줌 범위 넓히기 + 좀비 키 1.2m + 임시 1인칭(V)

## 원칙 (AGENTS.md)
모호하면 멈추고 보고 / 최소 코드 / 관련 줄만 / 목표 확인. UTF-8·한글 주석, perl 금지, Unity 조작·커밋 금지.
`V01SceneBuilder.cs` 전체를 읽지 말 것 (좀비 종류 데이터·`ApplyZombieModel`·관련 자기검사 약 4000~4030줄, 카메라 생성부만).

## A. 줌 (사용자: "좀 더 줌 할 수 있게")
`Assets/_Game/Scripts/Camera/IsometricCamera.cs` minZoom 3 → **1.5**, maxZoom 9 → **14** (기본 zoom 5.5 유지). 빌더가 값을 넣는 곳이 있으면 거기도. 자기검사에 범위 확인.

## B. 좀비 키 1.2m (사용자 결정, 플레이어와 같게)
- 실측(메인): 좀비 보이는 키 1.60m = cc.height 1.60, 플레이어 1.20m.
- 좀비 종류 데이터(`Data/Zombies/zombie_*.asset`) `bodyHeight` 1.6 → **1.2**, `bodyRadius` 0.3 → 0.26 (플레이어와 같게), `modelScale` 은 빌더가 다시 계산. 빌더가 이 값을 넣는 곳이 있으면 그 상수를 바꾼다.
- **좀비 눈높이**: 지금 몸 중심 + `Vision` 좀비 오프셋 0.3 → 1.2m 키면 지면 0.9m 가 되어 창턱(0.9)·조리대(0.95)에 시야가 막힌다. **좀비 눈높이도 지면 기준 1.15m** 로 (플레이어와 같은 방식). 08b 에서 좀비 0.3/플레이어 0.5 로 나눈 코드 참고.
- 1.6m 를 전제한 좀비 쪽 수치를 grep 해서 목록 보고, 깨지는 것만 고친다: 히트스캔 맞는 높이(자기검사 4014 `bodyHeight >= sweepBottom + 0.2`), 좀비 공격·물기 도달, 창 넘기(`VaultTarget(cc.height*0.5)`), 붙잡기, 좀비 공성(문 두드리기) 위치, 불러오기 높이, 좀비 도시 스폰.
- 플레이어 좀비(시체)는 이미 1.2m 라 그대로.

## C. 임시 1인칭 (V 토글, 마우스로 둘러보기)
- 새 런타임 클래스 1개 허용 (예: `FirstPersonView`, 플레이어 또는 카메라에 붙음). "임시" 라 최소 구현.
- V: 등각 ↔ 1인칭 토글. 1인칭이면:
  - 카메라 원근(FOV 70, near 0.05), 위치 = 플레이어 발 기준 눈높이 1.15m (머리 뼈 근처), 회전 = 마우스 이동(yaw/pitch, pitch ±80°), 커서 잠금·숨김. `IsometricCamera` 는 끔.
  - **조준 = 화면 가운데**: `PlayerAim.AimDirection`/`AimPoint` 가 카메라 정면(수평 성분)·화면 중심 레이캐스트를 쓰게. 몸 방향 규칙은 지금 그대로(조준 기준). 우클릭 조준·좌클릭 공격 규칙 그대로.
  - 이동: WASD 를 카메라 기준으로 (지금 등각 카메라 기준 계산을 1인칭 카메라 정면으로).
  - 위에서 보는 전용 효과 끄기: `VisionFog` 화면 덮개, `WallFader` 벽 흐림·지붕 숨김, `BuildingFloors` 층 숨김 → 1인칭 동안 모두 보이는 상태. 조준 커서 표시(AimCursorFx 등) 숨김.
  - 내 머리·머리카락 렌더러는 `ShadowsOnly` (화면을 가리지 않게), 몸·팔은 보임.
  - Tab(인벤토리)·UI 열리면 커서 풀기, 닫으면 다시 잠금.
- 다시 V: 원래 등각 상태로 정확히 복원 (줌·커서·효과·렌더러).
- 도시·별장 둘 다 동작 (빌더가 컴포넌트를 붙인다).

## 자기검사 (별장 Self Check, 도시 Check — 기존 유지)
1. 줌 범위 1.5~14.
2. 좀비 3종 bodyHeight 1.2, 보이는 키 1.2±0.03 (BakeMesh 기준, 플레이어와 같은 측정), 좀비 눈높이 지면 1.15±0.05.
3. 1인칭 컴포넌트가 있고, 토글 순수 함수(상태 → 끌 컴포넌트 목록) 확인 가능 범위.
4. 기존 검사 전부 통과 (특히 히트스캔·창 넘기·문 통과).
