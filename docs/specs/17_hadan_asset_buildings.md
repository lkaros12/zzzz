# 작업: 하단 도시 건물 459채를 Sketchfab 에셋 건물로 교체

## 원칙 (AGENTS.md)
모호하면 멈추고 보고 / 최소 코드 / 관련 줄만 / 목표 확인. UTF-8·한글 주석, perl 금지, Unity 조작·커밋 금지.
`HadanCityBuilder.cs` 중심. 별장 빌더·별장 동작 변경 금지.

## 사용자 결정
- 라이선스 신경 쓰지 말 것 (출시 안 함). **건물 전부 에셋으로 교체**, 실내·계단·들어가기는 없어져도 됨.
- 16번(실내)·15번(직접 만든 외관 장식)은 **코드를 지우지 말고** 상수 하나(`UseAssetBuildings = true`)로 끄고 에셋 경로를 탄다 (되돌릴 수 있게).

텍스처는 `Pack/Textures/*.png` (FBX 는 상대 경로). 일부 재질은 원래 텍스처 없는 단색.
**앞면 방향**: 블렌더에서 앞(간판)이 −Y 를 보도록 내보냈고 axis_forward=−Z 라 Unity 에서 앞면이 어느 축인지 **에셋을 열어 확인**하고(예: 간판 쪽 면 법선) 상수로 적어 둔다. 추측 금지 — 모르면 보고.

## 만들 것
1. **배치**: OSM 건물 다각형마다 최소 면적 회전 경계 상자(OBB, 변 방향 후보 중 최소)를 구한다.
   - 에셋 고르기(결정적, 건물 id 시드): 15번 유형별 — 상가 → bld_00/02, 상가주택 → bld_01/03/00, 주택 → bld_04/03, 아파트 → bld_00(가장 높음). 그 안에서 OBB 가로세로 비율이 가장 비슷한 것.
   - 앞면이 **가장 가까운 도로**를 보게 OBB 축 방향으로 회전.
   - 크기: X·Z 를 OBB 에 맞춰 늘이되 한 축 왜곡은 원본 비율 대비 1.6배까지(넘으면 다른 에셋 시도, 그래도 넘으면 1.6배에서 자르고 남는 면적은 비워 둔다). 높이 Y = 층수 × 3.6m (6층 상한 21.6m, 기존 층수 규칙 그대로) / 에셋 높이.
2. **한글 가게 앞면**: 상가주택·주택 중 도로 쪽 면 폭 ≥ 4m 인 건물에 shop_1/2/4 중 하나를 1층 앞면에 (건물 앞면에서 0.05m 바깥, 폭이 넓으면 1~2개 나란히). 상가(bld_00/02 자체 간판 있음)는 붙이지 않는다.
3. **충돌**: 건물마다 BoxCollider (OBB 크기·높이) — 통행·시야(Vision.BlockerMask, Default 레이어) 차단. 가게 앞면은 콜라이더 없음.
4. **가림 반투명**: 플레이어를 가리는 건물은 지금처럼 반투명 (`WallSegment` 외벽 방식 재사용 — 건물 인스턴스 하나를 한 조각으로). 에셋 재질마다 반투명 사본(URP Lit Transparent)을 **에셋으로 한 번** 만들어 공유(재빌드 누적 금지).
5. **유지**: 지면·도로·가로수·전봇대·전선·버려진 차·시작점·Arrive_FromEstate·부활 지점·도시 저장 차단. 이들의 "건물 외곽 1m" 배치 검사는 OSM 다각형 대신 **에셋 OBB** 기준으로.
6. **끄기 (UseAssetBuildings 일 때)**: 층·외벽·계단·문·BuildingFloors·간판/실외기/차양/옥상 소품(15·16번 생성 경로).
7. 정적 배칭, 같은 에셋 메쉬 공유. NavMesh 다시 굽기.
8. 로그: 에셋별 사용 수, 가게 앞면 수, 왜곡 잘림 수, GameObject·삼각형, NavMesh ms.

## 자기검사 (`Check Hadan Pilot`)
- 건물 459채 모두 에셋 인스턴스 + BoxCollider. 최고 높이 ≤ 21.6m.
- 모든 건물 X·Z 왜곡 ≤ 1.6배. 앞면이 가장 가까운 도로 쪽(앞면 법선과 도로 방향 각 < 60°) — 표본 50채.
- 시작점·Arrive 가 건물 콜라이더와 안 겹침, 15~50m 도로 경로 검사 통과.
- 반투명 사본 재질이 에셋 재질 수만큼 있고 재빌드 2번에 파일 수 같다.
- 16번 실내 검사(문·계단·층)는 UseAssetBuildings 면 건너뛴다(삭제 말고 조건).
- GameObject 25,000 이하.
