# 수정: 16 두 번째 실측 — 문 자리 NavMesh 빈 줄, 안쪽 벽 면 높이 0

원칙(AGENTS.md): 모호하면 멈추고 보고 / 최소 코드 / 관련 줄만 / 목표 확인. UTF-8·한글 주석, perl 금지, Unity 조작·커밋 금지.
**같은 문제로 두 번째 실패다. 추측으로 고치지 말고, 아래 사실과 별장의 동작하는 경로(`V01SceneBuilder.CreateOpening`, `BuildNavMesh`)를 비교해 원인을 확정한 뒤 고친다.**
원인을 확정할 수 없으면 코드를 바꾸지 말고 무엇이 필요한지 보고한다.

## 16c 이후 Check Hadan Pilot 실패 4건 (그대로)
법선 / "1층 외벽 메쉬가 문 중심을 막지 않는다" / "외벽 바깥면에 기존 외관 텍스처와 UV" / "문 앞→꼭대기 경로 0채".
콘솔: `Physics.ClosestPoint can only be used with a BoxCollider, SphereCollider, CapsuleCollider and a convex MeshCollider.` — **문 검사가 볼록 아닌 MeshCollider 에 ClosestPoint 를 써서 검사 자체가 틀렸다** (16c 가 "실제 콜라이더 기준" 으로 바꾼 부분).

## 메인 실측 (건물 `Building_556409324`, 문 (-171.78,1.2,233.28), forward (0,0,-1))
1. **외벽 구멍은 정상**: `ExteriorWall_1_0` 중심 (-168.3), `_1_1` 중심 (-175.2) 각각 폭 5.5 → 문 중심 ±0.7m 사이가 비어 있다(개구부 1.4m), 인방 `_1_2` 는 y 2.4~3.6. 문 중심을 가로지르는 수평 레이(y 0.3/1.0/1.8) 는 **문짝 `Pane` 만** 맞는다 (정상).
2. **문 자리 NavMesh 가 한 줄 통째로 없다**: 문 중심 기준 forward 오프셋 +1.6~+0.8 과 -0.8~-1.6 은 NavMesh 있음, **+0.4 줄은 가운데 3칸만, 0.0 줄은 옆 -1.2~+1.2 전부 없음**, -0.4 줄 일부만. 즉 벽 두께 구간에서 끊긴다.
   개구부 1.4m − 에이전트 반지름 0.3×2 = 0.8m 가 남아야 하는데 0 이다. → 굽기 때 문짝(Pane) 콜라이더가 빠지지 않았는지, 문 NavMeshObstacle(`Pane carve=True size 1,1,1`)·문틀이 굽기에 들어갔는지, 도시 굽기가 별장 `BuildNavMesh` 의 문 제외 경로를 실제로 타는지(도시 빌더 호출 순서: 문 생성 후 굽기인지) 확인.
3. **안쪽 벽 면 이상**: `Floor_1` 서브메쉬1(실내 벽면) 삼각형 8개가 모두 y 3.60~3.60 (**높이 0 인 퇴화 면**). `Floor_0` 서브메쉬1 은 y 0.00~2.40 (3.6 이 아니라 2.4 — 문 높이?). → 층마다 실내 벽면을 만드는 코드의 높이/기준 y 가 틀렸다. 법선 검사 실패의 원인일 가능성 높음 (16c 는 "검사가 틀렸다" 며 끝단을 검사에서 뺐는데, 되돌리고 메쉬를 고친다).
4. 계단: 계단 바닥→꼭대기, 꼭대기→위층 바닥은 PathComplete (이전 실측). 16c 에서 "0.4m 열린 입구" 를 넣었으나 문이 막혀 전체 경로는 확인 불가.

## 고칠 것
1. 문 자리 NavMesh (2번) — 원인 확정 후 수정. 문 중심 NavMesh 표본 자기검사 추가 (문 중심 ±0.2m 에 NavMesh 가 있다, 표본 20채).
2. 문 검사의 ClosestPoint 오류 → 볼록 아닌 콜라이더에는 레이/겹침 검사로.
3. 실내 벽면 높이 (3번) — 층마다 바닥 윗면 ~ 다음 층 바닥 아랫면 높이로. 16c 가 법선 검사에서 뺀 부분 되돌리기.
4. 외관 UV 실패: 16c 가 지붕을 UV 검사에서 뺐다. 실패가 계속되면 어느 메쉬·어느 면에서 실패하는지 로그에 첫 3개를 남기게 해서 원인을 보이게 (검사 완화 금지).
5. 계단 경로 검사가 문·계단 각각 어디서 끊기는지 첫 실패 건물 1개에 대해 구간별(문 밖→문 안, 문 안→계단 아래, 계단 위→꼭대기) 로그를 남기게.
