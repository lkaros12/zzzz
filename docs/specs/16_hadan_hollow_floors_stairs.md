# 작업: 하단 도시 건물 실내 1단계 — 속 비우기 + 층 + 계단 + 들어가는 문

## 원칙 (AGENTS.md 와 같다)
1. Think Before Coding — 모호하거나 코드와 안 맞으면 추측하지 말고 멈추고 보고.
2. Simplicity First — 별장 부품 재사용 우선. 새 런타임 클래스는 **층 가시성 1개만** 허용 (필요할 때만).
3. Surgical Changes — `HadanCityBuilder.cs` 중심. 런타임은 꼭 필요한 줄만. 별장 동작 변경 금지.
4. Goal-Driven Execution — 완료 기준별 확인 방법을 남긴다.
- UTF-8, 한글 주석("왜"), perl 금지, Unity 조작·커밋 금지. `V01SceneBuilder.cs` 전체를 읽지 말 것.

## 사용자 결정
**모든 건물(459채)** 에 들어갈 수 있고 **계단으로 위층까지**. 이번 16 은 뼈대만 (가벽·가구·루팅·창문은 17~19).

## 참고할 기존 부품 (메인 확인)
- `Room` (`Scripts/World/Room.cs`): 상자 모양(`InnerBounds`), `Room.At(point)`, `Setup(label, size)`. **다각형 건물에는 상자 판정이 밖을 포함**하므로 도시 층 판정은 다각형 포함 + 층 높이로 해야 한다.
- `WallSegment` (`Setup(opaque, fade, isExterior)`, `BindRoof(Room[])`, `Covers`, `SetVisible`, 지붕 큐 4001 처리), `WallFader` (실내면 지붕 숨김, 실외 가림 반투명 `FadeOutdoorOccluders`).
- 문: `WindowFrame` (문 모드 — 별장 현관문, `CanVault`, `PromptText`), 빌더의 `CreateOpening`.
- 층 높이: 도시 `FloorHeight` 3.6m (= 별장 `RoomHeight`). 최고 6층.
- 플레이어 키 1.2m, 반지름 0.26, stepOffset 0.35 (계단 한 칸은 이보다 낮게).

## 만들 것
1. **건물 = 층 단위 구조** (지금의 속 찬 덩어리 대신):
   - 층마다: 바닥판(두께 0.2m, 다각형 삼각분할 재사용, 콜라이더), **외벽**(다각형 변을 따라 두께 0.25m, 바깥면은 지금 외관 재질·UV 그대로 — 15번 외관이 유지돼야 한다), 안쪽 면은 실내 벽 재질(단색 밝은 톤, 유형별 2가지).
   - 지붕판은 지금처럼(초록 방수·난간·옥상 소품 유지).
   - 외관(간판·실외기·차양·가게 앞면)은 외벽 바깥에 그대로 붙는다.
2. **1층 문**: 05번 장식 문 위치에 **실제로 드나드는 문**(별장 문 부품 재사용, 열고 닫기, 좀비·시야 차단). 외벽에 그 폭만큼 구멍.
3. **계단**: 건물마다 계단실 1개 — 안쪽에서 가장 긴 변을 따라 모서리 쪽, 폭 1.2m, 한 칸 높이 ≤ 0.25m, 층마다 한 번 꺾는 되돌림 계단(또는 직선이 들어가면 직선). 위층 바닥에 계단 구멍.
   계단이 안 들어가는 작은 건물(안쪽 면적 부족)은 **1층만** 들어갈 수 있게 하고 로그에 개수.
   계단·계단실 벽에 콜라이더, NavMesh 로 오르내릴 수 있게.
4. **층 가시성 (좀보이드 방식)**:
   - 플레이어가 건물 X 의 N 층 안에 있으면: X 의 N+1 층 이상(벽·바닥·지붕·옥상 소품)은 숨긴다. N 층의 외벽 중 **카메라 쪽 면**은 반투명(기존 WallSegment 페이드 재사용).
   - 밖에 있으면 모든 건물 온전히 (기존 실외 가림 반투명 그대로).
   - 판정: 플레이어 위치가 건물 다각형 안 + 층 높이 범위 → 건물·층. 매 프레임 459채 전부 검사하지 말고 공간 격자나 가까운 건물만 (최소 구현).
   - 별장 `Room`/`WallFader` 로 되면 재사용, 다각형 판정 때문에 안 되면 **새 런타임 클래스 1개**(예: `BuildingFloors`) 허용.
5. **실내 시야**: 외벽·바닥이 `Vision.BlockerMask` 에 걸려 밖에서 안이 안 보이고, 안에서는 방 안이 보인다 (별장과 같은 규칙). 층 사이 바닥이 위·아래 시야를 막는다.
6. **NavMesh**: 계단 포함 전체 굽기. 굽기 시간 로그 (지금 약 10초, 3분 넘으면 보고).
7. **성능 묶음**: 층 바닥·외벽 안쪽 면은 건물·층 단위로 결합 메쉬 (숨기기 단위와 같게). 페이드가 필요한 외벽은 변 단위 조각이어도 된다 — GameObject 총 20,000 이하.
8. 로그: 계단 있는 건물 수 / 1층만 수 / 층 수 합계 / GameObject 수 / 삼각형 / NavMesh ms.

## 성능 한도 (메인이 잰다)
GameObject 20,000 이하, 고유 삼각형 300,000 이하, 재생 PlayerLoop +2ms 이하, 그리기 호출 400 이하.

## 자기검사 (`Check Hadan Pilot`, 기존 유지)
1. 모든 건물에 1층 문(실제 문 컴포넌트)과 외벽 구멍.
2. 계단 있는 건물: 1층 문 앞 → 꼭대기 층 바닥까지 NavMesh 경로가 이어진다 (무작위 5채 이상 표본).
3. 층 바닥 두께·계단 한 칸 높이 ≤ 0.25m.
4. 층 가시성 순수 판정 함수: (건물 안 N층 점) → (건물, N), (건물 밖 점) → 없음, 다각형 오목한 곳 바깥 점 → 없음.
5. 외관(간판·실외기 등) 개수가 15번과 같다 (외관이 사라지지 않았다).
6. 한도(GameObject·삼각형) 안.
