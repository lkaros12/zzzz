## 만들 것
1. **건물 유형별 후보 확장** (결정적, 건물 id 시드 그대로):
   - 상가 → 00, 02, 06, 07, 11
   - 상가주택 → 01, 03, 00, 09, 05, 06
   - 주택 → 04, 03, 05, 10, 08
   - 아파트 → 00, 12
   - 고르기 점수 = 지금의 OBB 가로세로 비율 차이 + **층수 차이**(에셋 높이/3.6 반올림 vs 목표 층수, 같은 가중치 정도). 낮은 단층 에셋이 6층으로 늘어나는 일을 줄이기 위함. 왜곡 1.6 규칙·잘림 처리는 그대로.
2. **가게 앞면 제외 목록**: 자체 간판 있는 에셋(00, 06, 07, 08, 09, 11)엔 가게 앞면을 붙이지 않는다 (지금 00 만 하던 것을 목록으로).
3. **버려진 차 교체**: 지금 상자 차 56대 자리·방향·개수 그대로, 상자 대신 차 FBX 인스턴스 (시드 결정적, 비율: 승용 계열 sedan·sports·suv·suv2·lanos 75%, truck 15%, bus·policebus 10%). 길이 방향을 도로 방향에 맞춘다. 콜라이더는 모델 경계 크기 BoxCollider(지금처럼 지정 콜라이더 검사 통과). 긴 차(버스)가 건물 외곽 1m·다른 소품과 겹치면 승용으로 바꿔 다시 시도. 정적 배칭, 메쉬 공유. 차 재질은 원본 FBX 재질 그대로(반투명 사본 필요 없음).
4. **도로 텍스처**: 도로 메쉬 재질(`hadan_road`)에 `road_atlas_baseColor` 를 쓰고 UV 를 아스팔트 부분(u 0.38~0.70, 차선 없는 곳)만 쓰게 한다 — 길이 방향은 미터 단위 반복(약 8m 에 1회). 지금 도로에 차선 표시 메쉬가 따로 있으면 그대로 둔다(없으면 만들지 않는다). 도로 메쉬·UV 생성 코드를 먼저 확인하고, 반복 타일링이 아틀라스 일부 구간에서 안 되는 구조면(UV 가 0~1 을 넘으면 옆 영역이 보임) 아스팔트 영역을 잘라낸 **별도 텍스처 에셋을 빌더가 한 번 만들어** 쓴다(재빌드 누적 금지).
5. **연석**: 도로 양쪽 가장자리를 따라 연석 띠(높이 0.15m, 폭 0.25m, `curb_baseColor`/`curb_normal`) — 도로 하나당 결합 메쉬 1개, 콜라이더 없음, NavMesh 영향 없음. 교차로에서 겹쳐도 무방(최소 구현). 연석이 건물 OBB 안으로 들어가는 구간은 신경 쓰지 않는다.
6. 로그: 에셋 13종 사용 수, 가게 앞면 수, 차 종류별 수, 연석 메쉬 수·총 길이, GameObject·삼각형·인스턴스 삼각형, NavMesh ms.
