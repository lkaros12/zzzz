## 사진에서 본 하단동 (메인이 이미지 검색으로 확인)
- **큰길(낙동대로·하단역 주변, primary/secondary 변)**: 5~10층 상가 건물. **벽면을 세로·가로 간판이 빽빽하게 덮는다** (빨강·파랑·노랑·초록·흰 바탕). 1층은 유리 가게 앞면. 일부 유리 커튼월(청회색).
- **골목**: 2~5층 **상가주택**(1층 가게 + 위층 주거). 벽: 붉은/갈색 벽돌, 베이지·흰 도장, 회색 타일, 짙은 회색 금속 패널(신축). 창문 방범창, 베란다 난간, 벽에 실외기.
- **옥상**: 주거 건물 다수가 **초록색 방수 페인트**, 파란·초록 물탱크, 작은 옥탑방.
- **거리**: 전봇대 사이 **전선 여러 가닥**이 길을 가로지름. 흰 고층 아파트 단지(동 번호).

## 만들 것
1. **건물 유형 분류** (결정적, 건물 id 시드): 
   - 상가건물: 주요 도로(primary/secondary) 15m 안 + 4층 이상.
   - 아파트: `building=apartments`.
   - 주택: 면적 < 100㎡ (실제 ㎡).
   - 나머지: 상가주택.
   분류 결과 개수를 로그에.
2. **벽 재질 팔레트** (유형별, 건물마다 하나 고름, 재질 공유):
   - 상가건물: 베이지 타일 / 회색 석재 / 청회색 유리 커튼월 / 흰 도장.
   - 상가주택: 붉은 벽돌 / 갈색 벽돌 / 베이지 도장 / 회색 타일 / 짙은 회색 금속 패널.
   - 주택: 흰·크림 도장 / 붉은 벽돌.
   - 아파트: 흰·아이보리 + 측벽 색 띠.
   벽돌·타일은 코드 생성 타일 텍스처(줄눈 패턴)로. 기존 창문 타일 텍스처와 곱해 쓰거나 유형별 창문 텍스처를 둔다 (상가: 넓은 띠창, 주거: 작은 창 + 방범창 격자, 아파트: 균일 창 + 베란다) — 가장 짧은 방법, 텍스처 수는 총 8장 이하.
3. **1층**: 상가건물·상가주택은 도로 쪽 1층 벽에 **가게 앞면 띠**(어두운 유리 + 문틀, 높이 3m) — 05번 문 위치와 겹치지 않게 문을 그 띠 안으로 흡수해도 됨.
4. **간판** (콜라이더 없음):
   - 상가건물: 도로 쪽 벽 2층~꼭대기까지 층마다 **가로 간판** (벽 폭의 60~95%, 높이 0.8~1.2m, 벽에서 5cm) 을 층의 50~80% 확률로, 모서리에 **세로 간판** 1~2개 (폭 0.8m, 높이 3~8m, 벽에서 수직으로 튀어나옴).
   - 상가주택: 1층 위 가로 간판 1개.
   - 간판 색: 빨강/파랑/노랑/초록/흰/주황 바탕. 글자는 **가짜 글자 무늬 텍스처**(코드 생성, 밝은 사각 블록 줄) 한 장을 공유해 바탕색에 얹는다. 약한 발광(Emission)으로 밤에 보이게.
   - 같은 색·크기는 메쉬·재질 공유, 정적 배칭.
5. **벽 부착물**: 주거 층(상가주택 2층 이상·주택·아파트)에 **실외기**(작은 박스, 창문 아래) 층당 0~2개, **베란다 난간**(아파트·상가주택 일부). 콜라이더 없음.
6. **옥상**: 주거 유형(상가주택·주택·아파트) 지붕 색 = **초록 방수 페인트**(두 톤), 상가건물 = 회색. 물탱크 색 파랑/초록 섞기. 상가주택·주택 30% 에 작은 **옥탑방**(박스, 2.4m, 문 하나 무늬). 05번 난간 유지.
7. **전선**: 인접한 전봇대끼리(30m 이내, 같은 도로) 전선 3가닥을 처지게(가운데 0.5m 늘어짐) 얇은 메쉬로 연결, 도로 건너편 전봇대끼리도 일부(20%) 연결. 콜라이더 없음. 전체를 몇 개 결합 메쉬로.
8. **아파트 동 번호**: 아파트 옆벽 위쪽에 큰 숫자 판(101, 102… 건물 순서) — 가짜 글자 대신 숫자 텍스처(0~9 한 장, 코드 생성 비트맵 폰트)로.
9. 로그 요약: 유형별 개수, 간판 수, 실외기 수, 옥탑방 수, 전선 수, 전체 삼각형.

## 성능 한도 (메인이 잰다)
- 씬 고유 삼각형 150,000 이하 유지, GameObject 수 8,000 이하 (지금 4,631), 재생 PlayerLoop +1ms 이하, 그리기 호출 300 이하.
- 이를 위해 간판·실외기·전선은 **재질별로 결합 메쉬**(건물 몇 개 단위 또는 칸 단위)로 만들어 GameObject 폭증을 막는다.

## 자기검사 (`Check Hadan Pilot` 에 추가, 기존 유지)
1. 유형 4가지가 모두 1개 이상. 상가건물 모두 도로 쪽 간판 1개 이상.
2. 간판·실외기·전선·옥탑방 문 무늬에 콜라이더 없음 (옥탑방 몸체는 지붕 위라 콜라이더 있어도 됨 — 없음 권장).
3. 주거 유형 지붕 색이 초록 계열.
4. 간판이 벽에서 0.3m 이상 떨어져 허공에 뜨지 않는다 (세로 간판은 벽에 한 변이 붙는다).
5. GameObject 수 8,000 이하, 고유 삼각형 150,000 이하.
6. 기존 경로 검사(15~50m) 통과, 시작점 5m 비움 유지.
