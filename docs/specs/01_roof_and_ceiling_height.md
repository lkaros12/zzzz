# 작업: 지붕 + 층고 3.6m + 실외 가림 반투명 (좀보이드 방식)

1. Think Before Coding — 명세가 모호하거나 코드와 안 맞으면 추측하지 말고 멈추고 보고한다.

   새 런타임 클래스는 꼭 필요할 때 1개까지. 만들면 이유를 보고한다.
3. Surgical Changes — 관련 줄만 고친다. 재포맷·무관한 변경 금지.
4. Goal-Driven Execution — 완료 기준별로 무엇이 확인하는지 남긴다.
- 파일은 UTF-8, 한글 주석이 많다. **perl 로 편집 금지**. 주석은 기존 스타일(한국어, "왜").

## 배경
아이소메트릭 카메라(부감 30도)가 위에서 내려다보는데 건물에 지붕이 없어서, 밖에 있을 때도 건물 안이 훤히 보인다.
사용자 요구: 밖에서는 건물 외관(지붕)이 보이고, 안에 들어가면 지금처럼 안이 보인다. 좀보이드와 같은 방식.

## 관련 코드 위치
- `Assets/_Game/Editor/V01SceneBuilder.cs` — 씬 빌더 + 자기검사.
  - `const float RoomHeight = 3.0f;` (약 4505줄). 벽·방 상자·월담 방지 천장(`CreateCeiling`)·전등(`CreateRoomLights`, `RoomHeight - 0.25`)·포치 기둥이 이 값을 쓴다.
  - 본채: `CreateApartment` (루트 `Apartment`). 차고+기계실: `CreateEstate` (`Apartment/Estate` 아래). 월드 좌표: 본채 바깥 벽 x 11.8~40.2, z -4.2~17.8.
    차고 바깥 x 2.6~17.0, z -25.1~-13.9. 기계실 바깥 x -5.4~2.6, z -20.3~-13.9.
  - 반투명 재질 헬퍼 `EnsureFadeMaterial`, 벽 조각에 불투명/반투명 재질을 묶는 방식은 `CreateWallPiece` / `BindWallVisual` 참고.
- `Assets/_Game/Scripts/World/WallFader.cs` — 카메라에 붙은 벽 투명화. 지금은 플레이어가 방 안일 때만 그 방 벽을 흐리고,
  실외에서는 `if (!CurrentRoom) return;` 으로 아무것도 안 한다.
- `Assets/_Game/Scripts/World/WallSegment.cs` — 렌더러별 불투명/반투명 재질 교체.
- `Assets/_Game/Art/Shaders/VisionFog.shader` — 시야 음영. 카메라 앞 판, `Queue=Overlay`, `ZTest Always`, 깊이로 월드 위치 복원.
- `Room.At(point)` — 그 지점의 방 (문간 0.3m 여유 포함). 실외면 null.

## 만들 것

### 1. 층고 3.0 → 3.6m
- `RoomHeight = 3.6f`. 벽·방 상자·월담 방지 천장·전등·포치가 따라 올라가야 한다.
- 문 높이 `DoorHeight`(2.6)·창문 높이(`WindowSillTop` 0.9, `WindowTop` 2.0)는 그대로.
- 이 값에 걸린 기존 자기검사(천장 밑면 = 벽 높이 등)가 새 값으로 통과해야 한다.

### 2. 보이는 지붕
- 건물마다 평지붕 1장: 본채 1개, 차고+기계실 하나로 1개 (둘은 붙어 있는 한 채로 본다).
- 바깥 벽을 덮고 사방으로 0.4m 처마. 두께 0.25m 정도, 윗면은 `RoomHeight` 바로 위.
- 짙은 회색 계열 재질 + 반투명 짝 재질 (벽과 같은 방식으로 흐릴 수 있어야 한다).
- **콜라이더 없음** (월담은 기존 보이지 않는 천장이 막는다). 시야 판정·조준·NavMesh 에 걸리면 안 된다.
- 지붕은 햇빛 그림자를 드리워도 된다.

### 3. 안에 들어가면 그 건물 지붕만 사라진다
- 플레이어가 있는 `Room` 이 속한 건물의 지붕을 **숨긴다** (렌더러 끄기). 다른 건물 지붕은 그대로.
- 나오면 다시 보인다. 문간(Room.At 의 0.3m 여유) 에서도 "안" 으로 친다.
- 지붕 ↔ 방 연결은 빌더가 만들 때 묶는다 (이름 규칙이나 좌표 추측으로 찾지 말 것).

### 4. 실외에서 건물이 플레이어를 가리면 그 건물을 반투명하게
- 실외일 때, 카메라 → 플레이어 사이를 가리는 **지붕과 바깥 벽 조각만** 반투명으로 (기존 SphereCast 방식 재사용).
- 가리지 않는 벽은 그대로 불투명이다 (사용자가 예전에 "밖에서 안 가리는 벽이 투명해지는 것" 을 버그로 지적했다).
- 안에 있을 때 기존 동작(그 방 벽 흐리기)은 그대로 유지.

### 5. 지붕은 시야 음영에 덮이지 않는다
- 밖에서 보면 지붕 아래는 벽에 막혀 "안 보이는 영역" 이라 음영이 지붕을 어둡게 칠한다. 좀보이드처럼 지붕은 항상 또렷하게 보여야 한다.
- 방법 제안: 지붕(불투명 상태) 을 음영 판(`Overlay`) **다음 큐**에 그려서 음영 위에 얹는다. 깊이 테스트는 유지해서
  지붕보다 앞에 있는 물체는 가려지지 않게. 더 단순하고 안전한 방법이 있으면 그걸 쓰고 이유를 보고한다.
- 반투명(가림) 상태의 지붕은 음영에 덮여도 된다.

## 새 자기검사 (기존 검사는 모두 유지)
1. 건물마다 지붕이 있다 (본채 1, 차고+기계실 1). 지붕이 그 건물의 바깥 벽 사각형을 사방 0.3m 이상 덮는다.
2. 지붕 밑면 ≥ `RoomHeight`, 콜라이더 없음, 시야를 막지 않는다(`Vision.BlockerMask` 기준).
3. 월담 방지 천장 밑면 = `RoomHeight`(3.6), 전등이 천장 밑, 방 상자 높이 = `RoomHeight`.
4. 지붕마다 연결된 `Room` 이 있고, 본채 지붕은 본채 방 11개, 부지 지붕은 차고·기계실을 가진다.
5. 지붕 불투명 재질의 렌더 큐가 음영 셰이더 큐보다 뒤다 (5번 방법을 큐로 했을 때).
6. 기존 문 머리 여유 검사(머리+stepOffset < 문 높이) 통과.
