아이소메트릭 생존 게임(GDD V0.1)의 우하단 HUD 2D 캐릭터 일러스트에 "겹칠 때 투명도 낮추기" 기능은 2026-09-15 에 구현 보류로 결정됨. 사용자가 직접 플레이해서 어떤 상황에서 가림이 실제로 불편한지 확인한 뒤 조건을 정하기로 했다.

**Why:** 카메라가 플레이어를 추적하므로 플레이어는 항상 화면 중앙에 있고, 일러스트는 화면 폭 74% 지점부터 시작한다. 즉 "플레이어와 겹침" 조건은 실제로 발동하지 않는다. 진짜 가려지는 대상은 우하단의 적·아이템·상호작용 오브젝트이며, 그게 실제 문제인지는 플레이 테스트로만 알 수 있다.

**How to apply:** 요청 없이 페이드 로직을 다시 넣지 말 것. 사용자가 구체적 케이스를 가져오면 그 조건으로 설계한다. 페이드와 별개로 일러스트 Image 의 Raycast Target 은 끄는 게 맞다(우하단 클릭 먹힘 버그).
